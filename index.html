Channel13 Auto-Poster

A private publishing tool for the Channel13📺 brand.

What it is

Channel13 Auto-Poster is a private automation tool run by the creator behind the Channel13 brand. It is not a public app: there is no public sign-up, no public login, and exactly one user — the operator.

What it does

Once a day, the tool publishes one original AI-generated short video to the operator’s own TikTok account, @channel13ai. Every video is a 100% original creation — never reposted, never third-party content. All content is PG-13: no politics, no religion, no conspiracy theories, and nothing graphic.

How it works

  • TikTok Login Kit — used solely to authorize the app to act on the operator’s own TikTok account. No other account is ever connected.
  • Content Posting API (Direct Post) — used to upload and publish the single daily video to @channel13ai.

No other TikTok APIs are used. The app performs no analytics, no tracking, and no audience interaction.

Connect

Connect TikTok

Connects the operator’s own TikTok account (@channel13ai) through TikTok Login Kit so the tool can publish the daily video. Only the operator can use this — there is no public sign-up.

Data practices

The app stores the TikTok authorization token required to publish, and the video file being posted. Tokens and videos are stored securely, never sold, and never shared with third parties. The operator can revoke the app’s access at any time in TikTok settings. Full details are in the Privacy Policy.

Contact

Reach the operator via TikTok: @channel13ai.
