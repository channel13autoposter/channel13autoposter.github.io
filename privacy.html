Privacy Policy

Effective: September 2026

Channel13 Auto-Poster is a private tool with a single user — its operator. It collects no data from the public and performs no analytics or tracking.

What the app touches

  • TikTok authorization tokens. When the operator authorizes the app through TikTok Login Kit on their own account (@channel13ai), TikTok issues access and refresh tokens. These tokens are used for one purpose only: publishing the operator’s daily video through the Content Posting API.
  • Video files. The original short videos the operator uploads for posting. Each file exists only to be published to @channel13ai.

What we do not collect

There are no public users, so there is no user data to collect: no names, no emails, no device identifiers, no analytics, no cookies for tracking, and no advertising data of any kind.

Storage and security

Tokens are stored securely on the operator’s own infrastructure and are never embedded in client-side code or public pages. Video files are held only as long as needed to publish them.

No sale, no sharing

Tokens, videos, and any related data are never sold and never shared with third parties for any reason.

Revoking access

The operator can revoke the app’s TikTok access at any time in TikTok’s settings (authorized apps / app permissions). On revocation, stored tokens are deleted and the app can no longer publish.

Contact

Privacy questions: contact the operator via TikTok at @channel13ai.
